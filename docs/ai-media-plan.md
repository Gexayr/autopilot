# AI-медиа для Автопилота: план (обсуждено 2026-10-31)

Автопилот = наш AI-SMM-щик. Следующий шаг: вместо (или вместе с) картинки-цитаты делать
короткие AI-видео и AI-картинки по теме контента, в том числе с персонажем пользователя.

## Решения

- **Отдельный сервис-генератор**: отдельный контейнер `generator` в этом же репозитории и с той же
  базой Postgres. Основное приложение ставит задание в очередь (таблица `media_jobs`), генератор
  берёт его, ждёт результат у провайдера (30 с - 5 мин), сохраняет файл, пост уходит на одобрение.
  Повторы при ошибках, таймауты, учёт расходов.
- **Адаптеры провайдеров** с одним интерфейсом (`generateImage`, `imageToVideo`, `status`), чтобы
  новый сервис подключался за пару часов.
- **Провайдеры по очереди**:
  1. **Alibaba Model Studio (Wan) напрямую**: основной и самый дешёвый. Регион Singapore,
     бесплатный лимит новым аккаунтам на КАЖДУЮ модель отдельно, 90 дней.
     wan2.2-i2v-flash 480p ~$0.015/с (клип 5 с ~ $0.075), wan2.6-i2v-flash 720p ~$0.025/с.
     Там же модели картинок (qwen-image-edit / wan image) для сцен с персонажем.
  2. **fal.ai** (вторым шагом): один ключ на Kling, Pika, Luma, PixVerse, Veo для отдельных тем.
- **Бесплатных API у Luma / Runway / Kling / Pika / PixVerse нет**: бесплатные кредиты только в их
  приложениях, через API не работают, автоматизировать приложения нельзя (бан, нарушение правил).
- **Бесплатный тариф Gemini не генерирует картинки** (лимит 0 для gemini-*-image, проверено
  2026-10-31). Для Gemini Image нужен платный ключ; пока используем модели картинок Alibaba.
- **Качество для старта**: 480p, вертикально 9:16, 5 секунд (меньше 5 с большинство моделей не
  умеет), без звука. В настройках контента позже выбор 480p / 720p.
- **Схема генерации (сначала картинка, потом видео)**:
  1. Gemini (текст, бесплатно) пишет сцену по теме контента: что в кадре, движение камеры, свет, 9:16.
  2. Модель картинок рисует кадр (с персонажем, если он задан).
  3. Кадр идёт на одобрение: если не нравится, потратили центы, а не стоимость видео.
  4. Wan оживляет кадр в 5-секундное видео; наш рендер накладывает цитату и подпись.
- **Выбор модели под тему (роутер)**: у каждой темы основная и запасная модель
  (еда -> Kling, недвижимость/туризм -> Luma, мотивация/природа -> Wan, люди/fashion -> Runway);
  лимит бюджета в месяц на провайдера и на пользователя; при исчерпании или сбое: следующая модель
  или обычная картинка-цитата. Бесплатные лимиты Alibaba расходуем по моделям по очереди.

## Персонаж пользователя (референсы)

- В настройках контента блок «Персонаж»: 1-4 картинки (лицо, в рост, ракурсы), имя, короткое
  описание, как часто использовать (каждый пост / иногда), галочка «права на персонажа есть».
- Модель картинок рисует новую сцену с тем же персонажем -> одобрение -> Wan оживляет.
- Нарисованные / 3D персонажи держатся хорошо, фотореалистичные лица могут «плыть».
  Реальных людей провайдеры могут отклонять (защита от дипфейков).
- Тест на роботе-астронавте (3 референса от владельца) ждёт ключ Alibaba.
- Персонаж похож на Astro Bot (Sony). Для теста ок; для публикации чужого персонажа в Instagram
  есть риск жалобы правообладателя.

## Этапы

1. Ключ Alibaba Model Studio -> тест: сцены с роботом (картинки) + оживление одной в видео.
2. Генератор: контейнер, `media_jobs`, адаптер Wan (картинка + image-to-video), учёт расходов.
3. В контенте настройка «Тип Reels»: «Цитата на фоне» (как сейчас, бесплатно) / «AI-видео».
   Одобрение кадра до оплаты видео (сайт + бот).
4. Персонаж: загрузка референсов, использование в сценах.
5. Роутер по темам + бюджеты; fal.ai (Kling, Pika, Luma) для отдельных тем.
6. Неделя на @his_power22 / @echo_of_time22: сравнить охваты AI-видео с текущими Reels.

## Стоимость (ориентир)

1 Reels в день на контент: 480p Wan ~ $2-3 / месяц; Kling/Luma ~ $6-12 / месяц.
Первые недели, скорее всего, бесплатно за счёт лимита Alibaba. Заложить в будущие тарифы
(«N видео в месяц»).

## Пока не делаем

- Прямой reference-to-video (видео сразу по референсам, без кадра).
- Вход по email/паролю (позже: вход по ссылке из письма, когда пойдут платные клиенты).
- Вход через Instagram (только после проверки Meta / App Review).
